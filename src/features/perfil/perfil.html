Cómo se calcula

Cada interés seleccionado suma peso a su categoría; el resto se distribuye con un valor base bajo para reflejar afinidades latentes. El nombre del perfil ("Explorador Urbano", "Voz de Barrio"...) se asigna según la categoría con mayor peso.
